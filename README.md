# IntegraTrip / MagnaTrip

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```


URL para acceder a la página: https://integratrip-temp.vercel.app

# IntegraTrip

## Dataset

- **Ediciones:** Traveling 69 a 78.
- **Identificador:** `gasparmagnar/integratrip-magazines`.
- **Mapa público:** <https://atlas.nomic.ai/data/gasparmagnar/integratrip-magazines/map>

## Exploración de Atlas

- **Temas:** destinos, gastronomía, vinos, arquitectura y cultura.
- **Destinos:** Algarve, Huelva, Lipari, Costa Rica, Asturias, Burgos, La Rioja
  y Castellón, entre otros.
- **Clusters:** sí; agrupan principalmente destinos, gastronomía, arquitectura
  y contenido editorial.
- **Chunks duplicados:** sí; hay 18 grupos idénticos, principalmente créditos
  repetidos entre ediciones.
- **Chunks irrelevantes:** sí; hay créditos, contactos, índices y publicidad.
- **`playas`:** aparecen resultados del Algarve, Playa de las Catedrales, Playa
  Naranjo, Canneto y Huelva.
- **`castillos`:** aparecen el Fuerte de San Felipe, Santa Gadea del Cid y el
  Castillo de los Velasco.
- **`comida romántica`:** el resultado principal es el restaurante
  VelascoAbellà.
